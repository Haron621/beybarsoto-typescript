# Beybars Oto Servis — TypeScript

TypeScript/React-версия сайта из `E:\ALEKSEI\beybarsoto`.

## Запуск

```powershell
npm install
npm run dev
```

## Проверка и сборка

```powershell
npx tsc --noEmit
npm run build
```

Основные файлы:

- `app/page.tsx` — страница React;
- `app/site-markup.ts` — статическая разметка сайта;
- `app/site-controller.ts` — клиентская логика и переводы;
- `app/globals.css` — стили;
- `public/` — изображения и статические файлы.
